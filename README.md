# Secure Bank API — AppSec Lab

This project simulates a real-world banking system designed to model application security vulnerabilities and secure implementations.

## 🔐 Security Features Implemented

- JWT-based authentication and authorization
- Role-based access control
- Secure user identity extraction via SecurityContext
- Transaction handling with concurrency considerations
- Path traversal protections
- File upload handling (with security modeling)
- Global exception handling

## 🧠 AppSec Focus Areas

This system is used to model and analyze:

- Access control flaws (IDOR, privilege escalation)
- Trust boundaries (controller vs service vs DB)
- Race conditions and TOCTOU
- Input validation and file handling risks
- Authentication vs authorization failures

## 🚀 Upcoming Enhancements (Phase 2)

- Docker containerization and hardening
- Cloud security mapping (IAM, network segmentation)
- DevSecOps pipeline enforcement (SAST, DAST, policy gates)
- Microservices expansion (audit-service)

## 🎯 Purpose

This project is part of a structured training plan to reach senior-level application security expertise by simulating enterprise-grade systems and attack scenarios.
